# 部屋の寸法3D（試作）

部屋の形と寸法を1問ずつ答えると、部屋と家具を3Dにして、通り道が60cm取れるかを確かめられます。

**目安です。発注前に必ず実測してください。**

## 使い方
1. 「始める」を押し、部屋の形（長方形／L字）を選ぶ
2. 赤く光る壁の長さを、1問ずつ cm で答える（分からなければ「分からない」で標準の値を入れ、「推定」の印がつく）
3. ドア・窓、置きたい家具（幅・奥行・高さ）を答える
4. 3Dで家具を指で動かす。通り道が60cmを下回ると知らせる（目安）

「間取り図から作る（家全体）」を選ぶと、1つの階の間取り図の画像から壁と部屋の下書きを自動で作ります。間取りソフトや広告のカラーの図（壁が濃い太い線）に向いています。下書きは、壁を足す・消す・動かすで直せます。部屋の名前を選び、部屋1つの畳数で縮尺を合わせ、ドア・窓を置くと、全部の部屋を1つの3Dにして、部屋ごとに家具を置けます。

「見本の家（架空）」では、架空の家の床・壁・ドア・キッチン・家具を変えて、見た目と通り道の目安を試せます（間取り・寸法はすべて架空です）。

「1部屋だけなぞって作る」を選ぶと、間取り図の画像を下絵にして、長さが分かる所（または畳数）で縮尺を合わせ、部屋の角とドア・窓をタップしてなぞれます。広告の間取り図は縮尺が正確でないことが多いため、読み込んだ寸法はすべて目安（推定）です。発注前に必ず実測してください。

## 入力した値について
- 入力した寸法は、この端末の外に送りません（通信・ログイン・課金なし）。
- 間取り図の画像は、この端末の画面に下絵として出すだけです。送らず、保存もしません（保存されるのはなぞった寸法だけです）。
- 入力はこの端末のこのブラウザの中にだけ保存されます。しばらく開かないと消えることがあるので、大事なものは「保存を書き出す」でファイルにしてください。
